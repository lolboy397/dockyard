Restoring & the encryption key
  • Backups are written to the host directory set by BACKUP_HOST_DIR (default ./backups). Point it at an external disk or NAS for true off-host durability.
  • Restore is a host-side procedure (you can’t hot-restore the live database): stop the stack, replace the backend-data volume contents with the archive, then start again — see BACKUP.md.

# Dockyard — Marketing UI Kit

The Dockyard marketing site — same dark, dense, technical brand as the app but with breathing room and oversized type.

## Files

- **`index.html`** — full marketing page.
- **`marketing.css`** — page styles (imports tokens).
- **Sections built inline** in `index.html` for editability — `Nav`, `Hero`, `LogoStrip`, `FeatureGrid`, `BigQuote`, `Showcase`, `Pricing`, `CTA`, `Footer`.

## What's faked

All links go nowhere, the Buy/Try buttons don't post anywhere, copy is illustrative. Hand off to the writer for real copy.

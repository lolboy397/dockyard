Everything in one place

Built for the parts of Docker that actually take your day

Twelve panels' worth of tooling, collapsed into one fast, keyboard-driven surface.

Containers, observably
Live CPU, memory and network per container. Tail logs from anywhere. Open a shell with one keystroke.
Image graph
See every layer, every reference, every byte you can reclaim. Prune confidently, never accidentally.
Compose with diff
Edit compose files, see exactly what'll change before you apply. Roll back the whole stack with one command.
Networks, mapped
Visual topology of every bridge, overlay and host network. Trace the path a request takes, end to end.
Registry, unified
Docker Hub, GHCR, ECR, GAR, ACR — and your private registry. Search them like they're one.
Keyboard first
Every action is a command. ⌘K jumps to anything. Memorize twelve shortcuts, run the system.
Teams + RBAC
Granular roles across environments. Approval workflows for destructive ops. SSO + SCIM on day one.
Audit & compliance
Every action signed and logged. SOC 2 + ISO 27001 ready. Stream events to your SIEM.
Metrics, native
Per-container Prom-compatible metrics. Pin the views you live in. Alert on anything.
